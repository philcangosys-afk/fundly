# لوحة تحكم فَندلي

لوحة ويب لإدارة بيانات تطبيق **fundly** من قاعدة Supabase نفسها، بهوية
التطبيق: عربية RTL، خط Cairo، وألوان `AppTheme`.

مبنية على قالب Builder.io الأصلي (Vite + React + Express + Netlify)، مع
استبدال الأرقام الوهمية في التصميم ببيانات حقيقية.

## التشغيل

```bash
npm install     # أو pnpm install
npm run dev
```

ثم افتح `http://localhost:8080` وسجّل الدخول ببريد حساب التطبيق وكلمة مروره
(نفس ما في `lib/config/supabase_config.dart` داخل تطبيق fundly).

## الإعداد

`.env`:

```
VITE_SUPABASE_URL=https://pcppwpbaknxflzbqbrxj.supabase.co
VITE_SUPABASE_ANON_KEY=<المفتاح العام>
```

إن لم يوجد الملف تعمل اللوحة بالقيم الاحتياطية في `client/lib/supabase.ts`.
المفتاح المستعمل **anon** فقط؛ مفتاح `service_role` لا يوضع في كود المتصفح —
ما يحتاجه يُنفَّذ في `server/`.

## الصفحات

| الصفحة | ماذا تعرض |
|---|---|
| نبض المنتج | حجم البيانات ونموّها شهريًا، أكثر الجداول امتلاءً، أنواع الالتزامات المشتركة، تفويضات تقارب الانتهاء، دفعات إيجار متأخرة، أحدث ما أُضيف |
| التفويضات | كل تفويض بحالته المحسوبة (ساري/قارب الانتهاء/منتهٍ/موقوف/مجدول) مع إيقاف وتشغيل مباشر |
| المستندات والتخزين | المستندات المنشأة من القوالب، والمرفقات وأحجامها وأكبرها |
| الجداول | مستعرض لكل جدول: بحث، فلتر حالة، صفحات، تصدير CSV، وفتح السجل كاملًا بما فيه حقول JSON |
| سلامة البيانات | صفوف يتيمة، سجلات بلا `user_id`، عقود وتفويضات انتهت ولم تُحدَّث |
| الإعدادات | حالة الاتصال، وما تراه اللوحة وما لا تراه |

## معروف ومقصود

- القراءة دائمًا `select('*')`، و`client/lib/schema.ts` يعطي التسميات العربية
  وترتيب الأعمدة فقط — فعمود جديد في قاعدة البيانات يظهر تلقائيًا.
- **الأفراد والجهات** و**التنبيهات** في التطبيق محفوظة في `SharedPreferences`
  على الجهاز لا في Supabase، فلا تظهر هنا.
- التطبيق يدخل بحساب واحد مشترك، فكل السجلات تحمل نفس `user_id`. أقسام
  «المستخدمون» و«الاشتراكات» و«الدعم» معطّلة في القائمة حتى تُفصل الحسابات
  وتُفعّل RLS لكل مستخدم.
