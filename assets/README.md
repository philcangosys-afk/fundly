# مجلد Assets - Fundly

## بنية المشروع

```
fundly/
└── assets/
    ├── images/
    │   ├── splash_1.png    (الشاشة الأولى - نظم التزاماتك)
    │   ├── splash_2.png    (الشاشة الثانية - شارك وادفع)
    │   ├── splash_3.png    (الشاشة الثالثة - ثقة وشفافية)
    │   └── logo.png        (شعار التطبيق)
    └── README.md
```

## تعليمات إضافة الصور

### 1️⃣ الصور المطلوبة

قم بضع الصور التالية في مجلد `assets/images/`:

#### الشاشة الأولى (splash_1.png)
- **الموضوع**: "نظم التزاماتك بكل سهولة"
- **الأبعاد الموصى بها**: 400x320px
- **الوصف**: محفظة بنفسجية مع عملات ذهبية

#### الشاشة الثانية (splash_2.png)
- **الموضوع**: "شارك وادفع مع أصدقائك"
- **الأبعاد الموصى بها**: 400x320px
- **الوصف**: مجموعة أشخاص مع عملة ذهبية كبيرة

#### الشاشة الثالثة (splash_3.png)
- **الموضوع**: "ثقة وشفافية مطلقة"
- **الأبعاد الموصى بها**: 400x320px
- **الوصف**: درع أمان مع علامة تصحيح

### 2️⃣ كيفية استخدام الصور

بعد إضافة الصور، قم بتحديث ملف `lib/screens/onboarding_screen.dart` لاستخدام الصور:

```dart
// مثال على الاستخدام
Image.asset(
  'assets/images/splash_1.png',
  width: 400,
  height: 320,
)
```

### 3️⃣ إعادة تشغيل المشروع

بعد إضافة الصور، قم بتشغيل الأوامر التالية:

```bash
flutter clean
flutter pub get
flutter run
```

## ملاحظات هامة

- ✅ تأكد من أن أسماء الملفات **تطابق بالضبط** مع أسماء في الكود
- ✅ استخدم صور بجودة عالية (PNG أو SVG)
- ✅ تأكد من أن الصور بصيغة صحيحة
- ✅ يمكنك استخدام أي أداة تصميم (Figma, Adobe XD, إلخ)

## مثال على هيكل pubspec.yaml

```yaml
flutter:
  uses-material-design: true
  
  assets:
    - assets/
    - assets/images/
```
