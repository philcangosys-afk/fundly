# 🎯 نظام الإضافات الذكي للالتزامات

## 📖 نظرة عامة

نظام متقدم لعرض الإضافات بطريقة ذكية ومنظمة:
- ✅ **إضافات منطقية** - تظهر مباشرة حسب نوع الالتزام
- ✅ **زر "مزيد من الإضافات"** - للخيارات الإضافية
- ✅ **تصميم تفاعلي** - قابل للتوسع والطي

---

## 🗂️ الملفات المُنشأة

| الملف | الوصف |
|------|------|
| `lib/config/commitment_additions_config.dart` | تكوين الإضافات لكل نوع التزام |
| `lib/widgets/commitment_additions_menu.dart` | Widget القائمة التفاعلية |
| `lib/screens/commitment_details_example_screen.dart` | مثال عملي شامل للاستخدام |
| `lib/ADDITIONS_USAGE_EXAMPLE.md` | دليل الاستخدام التفصيلي |

## 🚀 البدء السريع

### 1. استيراد الملفات

```dart
import 'package:fundly/widgets/commitment_additions_menu.dart';
import 'package:fundly/config/commitment_additions_config.dart';
```

### 2. عرض القائمة

```dart
// في أي شاشة تريد عرض الإضافات
ElevatedButton(
  onPressed: () async {
    final selected = await showCommitmentAdditionsMenu(
      context: context,
      entryType: 'مصروف شخصي', // نوع الالتزام
      commitmentId: 'commitment-123',
    );
    
    if (selected != null) {
      print('تم اختيار: ${selected.displayName}');
      // تعامل مع الإضافة المختارة
    }
  },
  child: Text('إضافة جديدة'),
)
```

## 🔧 التخصيص

### تعديل الإضافات المنطقية

افتح `commitment_additions_config.dart` وعدّل:

```dart
case 'مصروف شخصي':
  return [
    AllAdditions.payment,      // أضف
    AllAdditions.receipt,      // أو
    AllAdditions.image,        // احذف
    AllAdditions.note,         // أو رتب
  ];
```

### تعديل الألوان

في `commitment_additions_menu.dart`:

```dart
// لون الإضافات المنطقية
color: isPrimary ? Colors.blue.shade50 : Colors.grey.shade50,

// لون الحدود
border: Border.all(
  color: isPrimary ? Colors.blue.shade200 : Colors.grey.shade300,
),
```

## 📱 الاستخدام في تطبيقك

### الخطوة 1: استبدل الكود القديم

إذا كان لديك كود قديم لعرض الإضافات، استبدله بهذا:

```dart
// القديم ❌
void _showOldAddMenu() {
  showDialog(...);
}

// الجديد ✅
Future<void> _showAddMenu() async {
  final selected = await showCommitmentAdditionsMenu(
    context: context,
    entryType: commitment.entryType,
    commitmentId: commitment.id,
  );
  
  if (selected != null) {
    _handleAddition(selected);
  }
}
```

### الخطوة 2: معالجة الإضافات

```dart
void _handleAddition(AdditionType addition) {
  switch (addition.category) {
    case AdditionCategory.payment:
      // افتح شاشة إضافة دفعة
      Navigator.push(context, MaterialPageRoute(
        builder: (_) => AddPaymentScreen(commitmentId: id),
      ));
      break;
      
    case AdditionCategory.attachment:
      // افتح picker للملفات
      _pickAndUploadFile(addition);
      break;
      
    // ... باقي الحالات
  }
}
```
